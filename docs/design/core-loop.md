# Core Loop — Le Prime 3 Ore

> "Se le prime 3 ore non sono magnetiche, il progetto muore."

---

## 1. Principio

Il core loop deve rispondere a tre domande:
1. **Cosa fa il giocatore ogni 5 minuti?** (micro-loop)
2. **Cosa fa il giocatore ogni ora?** (meso-loop)
3. **Cosa fa il giocatore tra sessioni?** (meta-loop)

---

## 2. Micro-Loop (5 minuti)

```
SCANSIONA → ANALIZZA → DECIDI → AGISCI → VERIFICA
```

Il giocatore dalla capsula Panopticon:
1. **Scansiona** il terreno/risorse circostanti tramite droni/sensori
2. **Analizza** i dati ricevuti (composizione suolo, energia disponibile, rischi)
3. **Decide** la prossima azione (costruire, estrarre, esplorare, riparare)
4. **Agisce** tramite controllo remoto (braccio robotico, drone, rover)
5. **Verifica** il risultato e adatta

**Tensione costante:** ogni azione consuma energia. Il timer energetico e' sempre visibile.

---

## 3. Meso-Loop (1 ora)

```
ESPLORA → COSTRUISCI → STABILIZZA → ESPANDI
```

1. **Esplora** — scopri nuove zone, scansiona il terreno, trova risorse
2. **Costruisci** — piazza strutture, moduli, generatori
3. **Stabilizza** — mantieni l'equilibrio energetico, ripara, ottimizza
4. **Espandi** — allarga il raggio operativo, collega a reti

**Momento chiave:** dopo ~45 minuti, il giocatore dovrebbe avere la prima infrastruttura funzionante.

---

## 4. Meta-Loop (tra sessioni)

```
PIANIFICA → ASPETTA → RACCOGLI → EVOLVI
```

1. **Pianifica** — prepara blueprint, strategie, accordi con altri giocatori
2. **Aspetta** — processi in tempo reale (costruzione, ricarica, crescita)
3. **Raccogli** — risorse accumulate, risultati di processi automatici
4. **Evolvi** — l'IA custode elabora i sogni, offre nuove prospettive

---

## 6. Tasso di Mortalita' Ideale

> "Quanto deve morire un giocatore medio?"

### Target:
- **Morte nelle prime 10 ore:** ~15% dei giocatori
- **Morte nelle prime 50 ore:** ~30% dei giocatori
- **Morte dopo 100 ore:** ~5% per sessione di 10 ore

### Cause di morte (distribuzione):
- 40% — Errori energetici (cattiva gestione risorse)
- 25% — Eventi ambientali (tempeste, guasti)
- 20% — Conflitti con altri giocatori
- 15% — Esplorazione rischiosa

### Principio chiave:
La morte non e' mai "ingiusta". Il giocatore deve sempre capire PERCHE' e' morto.
L'IA custode nella vita successiva ricorda e commenta.
